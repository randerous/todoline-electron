# 0.1.46

- 已识别的链接右键新增“打开链接”；按住 Ctrl 指向链接显示手形指针。
- 有序列表右键将“继续编号”和“重新编号”并列显示。重新编号从当前项开始计数，保留上方编号、下级列表和格式，可撤销。
- 正文和分隔线右键新增“置顶事件”：整段移到文档顶部，保留事件 ID、创建时间、截止时间、完成状态、富文本和图片引用，可撤销。
- 搜索改为独立浮动窗口。握柄和空白区域可在桌面拖动，移出主窗口后内容完整显示；主题、跨文件搜索、高亮、快捷键同步。关闭搜索、切换标签、隐藏和恢复主窗口均处理浮窗生命周期。
- 新启动图标采用深色渐变底、浅色上下线与蓝色中线，长度比例为 14∶16∶12。应用内标识保留原样。

验证：810 项单元测试通过；类型检查及生产构建通过。针对上述功能以及跨文件搜索、标签状态、原生快捷键和主题的端到端检查通过。发布后另直接启动最终 EXE 运行新增的四项端到端检查，结果见发布验证记录。

便携包：`dist/TodoLine-Electron-0.1.46-win-x64.zip`。

本机可执行文件：`dist/release-0.1.46/win-unpacked/TodoLine Electron.exe`。打包改用版本独立目录，避免正在运行的旧版本占用输出目录。
