# 文件差异对比

选中第二个或之后的标签，点击工具栏的 **与前一个标签比较** 按钮，对比当前标签与紧邻其左边的标签。左侧显示前一个文件，右侧显示当前文件。Compare 标题栏以“从左侧修改到右侧，需：”说明新增、删除、修改的方向，字号统一。没有前一个标签或两者文件模式不同时按钮禁用。

文件模式分为 TDE、Markdown 和纯文本：`.txt`、`.log`、`.cfg` 等纯文本后缀可以互相对比。使用标签当前的内存内容，包括尚未保存的编辑；打开对比不会主动保存、合并或改写文件。

- 新增行绿色、删除行红色，修改行黄色；行内修改使用更明显的色块，左右行号独立显示，缺失行用占位区域对齐。
- 两栏同步垂直滚动，横向可各自查看长行。上/下按钮、F7 / Shift+F7 跳转上一处/下一处差异，Esc 或关闭按钮返回原文档。
- Markdown 对比源码；TDE 对比正文文本、分隔线创建时间、截止时间与完成状态，不对比内部数据库 ID、图片像素及纯样式变化。
- 比较保留空格、Tab 和末尾空行差异；CRLF、CR、LF 按相同换行处理，不将编码和换行形式作为正文差异。
- 对比视图和 Worker 按需加载。计算在 Worker 中运行，关闭时终止；按可见范围渲染行。算法以公共唯一行为锚点，对高差异区域设计算上限；无法精细对齐的区域保留完整内容并按整段对齐显示。

验证覆盖插入/删除、行内多个修改、Unicode、空文件、重复行、随机文本重建、两万行算法样本、8,000 行真实窗口滚动、标签顺序、文件类型、未保存内容、深浅主题和关闭恢复。测试文件：`tests/diff-engine.test.ts`、`tests/e2e/diff.spec.ts`。
