# 0.2.3

- 标签重命名输入取消蓝色边框与额外焦点描边，保留原有标签顶部指示条、选中文字、非法文件名提示和键盘操作。
- 事件导航高亮左侧改用独立的 2px 竖线，上下略留空；金色搜索匹配也采用同样形式。
- 左下角新增快速搜索，按当前文件正文或截止时间筛选事件；Enter 定位首个结果，Esc/清除按钮恢复列表。文件夹图标位于日历左边。Markdown 文件对应搜索目录标题。Ctrl+F 原有全列表匹配高亮行为继续保留，除非用户另行使用快速筛选。
- 纯文字对外只提供 Windows Unicode 文本，不提供公共 HTML，避免 Office 将富文本作为新对象粘贴。Markdown 输出可读正文、代码和公式源码，不附加 Markdown 格式标记。
- 被复制的实际事件分隔线输出 `====`，保留创建时间、截止时间及可用的剩余时间/完成状态。单独复制后面的事件也保留它自己的分隔线。
- 图文混合继续提供 HTML，并将 TDE 图片编号转换成携带原图数据的地址；单张图片的原生图片复制继续保留。
- 软件私有 HTML 与 TDE 事件格式独立保留，内部粘贴不会因为纯文本对外输出而丢失格式。

## 验证

类型检查、生产构建通过。58 项相关单元测试、4 项 Windows 剪贴板专项、10 项打包程序界面/复制/导航专项通过。只测试修改部分及其直接回归。

安装在本机的 PowerPoint 通过 COM 创建临时空白演示文稿，在现有文本框 `AB` 的指定文本位置粘贴从 TodoLine 复制的加粗文字 `PasteText`，结果为 `APasteTextB`，幻灯片始终只有 1 个文本框。未保存测试文稿。此项验证文本范围插入，不是对任意 Office 版本的手工 Ctrl+V 测试。

图文混合验证了公共 HTML 存在、原图数据可携带、私有数据保留；未断言所有外部程序对 HTML/图片的呈现完全一致。

旧导航测试原先假设滚动 400px 后必定只显示一个事件，在当前窗口实际显示两个事件时失败；改为用实际正文几何范围核对全部可见 ID，复测通过。
