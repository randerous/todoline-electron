# 0.2.1

- 新文档以本地日期加序号命名，每天从 `_0` 开始，重启保留当日序号，避开同目录已存在的 TDE/Markdown 名称。
- 清理本版本起创建、未改名、没有正文的文件：关闭标签及正常退出时执行，同时移除会话与最近文档记录。曾有内容后清空也适用。已有外部文件、改名过的文件、图片、表格、提醒信息、外部修改或恢复冲突均保留。仅关闭到托盘不清理。
- 新建空白文件重命名前先同步编辑器中的空事件，避免重命名完成后编辑器无法切换到新路径。
- 设置中移除保存目录下方的说明文字。
- 原图适应窗口支持等比放大和缩小；适应模式下窗口尺寸变化会重新计算比例，手动缩放则保留用户比例。移除底部操作提示，错误提示仍保留。
- 关闭原图恢复焦点时不滚动页面；搜索结果与请求绑定，重复关键词、重新打开搜索和替换查询都可直接定位，跨文件逐项查找不回跳到首项。
