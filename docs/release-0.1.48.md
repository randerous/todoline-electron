# 0.1.48

- `Ctrl+T` 置顶光标所在事件；选中单个事件时置顶该事件。正文和分隔线右键菜单显示快捷键，支持撤销，并遵守只读限制。
- 提醒窗的稍后提醒按钮可直接编辑时间，默认“10 分钟”。支持与截止时间相同的解析，例如“5分钟”“2小时”“3天后”“半小时”。点击右侧“后提醒 / 提醒”或按 Enter 生效；每条新提醒恢复默认时间。无效或过去的时间会提示错误并保留当前提醒，自定义提醒时间持久保存。
- 空列表行按 Backspace 先取消序号，保留缩进；继续按 Backspace 每次取消一级缩进，直到顶格。支持有序、无序、嵌套和单独缩进的列表，保留周围内容与编号，支持撤销及保存恢复。

仅验证本次相关功能，未运行全量测试。测试和发布包验证结果见 `packaged-0.1.48.json` 与 `release-0.1.48.json`。
