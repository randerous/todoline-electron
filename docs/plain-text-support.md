# 纯文本文件

文件路由按后缀判断：`.tde` 使用事件数据库；`.md` 和现有兼容后缀 `.markdown` 使用 Markdown；其余后缀及无后缀文件按纯文本打开。

文件对话框、启动参数/系统“打开方式”、已有实例收到的打开请求、最近文档、会话恢复和拖入均支持纯文本。富文本编辑器中的图片拖入继续沿用插入图片行为。

纯文本编辑器按需加载，只有文本和行结构，不解析 Markdown/HTML，不自动转换文件格式，不加载 Markdown、公式或代码高亮模块。支持编辑、撤销、复制/剪切/粘贴、快速搜索和 Ctrl+F；富文本与事件专属操作禁用。

保存使用现有文本存储的原子写入、版本校验、外部修改检查、恢复日志与另存为机制。保留文件原后缀，支持 UTF-8（含 BOM）和带 BOM 的 UTF-16 LE/BE，并保留原换行风格及空白。未编辑时不重写文件。无效编码或检测到的二进制内容报错，原文件不修改。

当前不自动猜测 GBK 等其他编码；此类文件需先转换编码。纯文本另存为保持原模式。重命名支持修改完整后缀：改为 `.md` / `.markdown` 时将原文作为 Markdown 解析，改为 `.tde` 时创建实际事件数据库并保留原文件恢复副本；UTF-16 改为 Markdown 时转换为 UTF-8。

专项测试：`tests/plain-text-store.test.ts`、`tests/plain-text-editor.test.ts`、`tests/e2e/plain-text.spec.ts`；相关回归包含 Markdown、启动参数、文件名及快速搜索。
