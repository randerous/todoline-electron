# 0.2.5

- 新增纯文本文件模式：除 `.tde`、`.md`、`.markdown` 外的其他后缀及无后缀文件，以纯文本打开、编辑和保存，支持命令行、文件对话框、拖入、最近文档和恢复标签。
- 保留纯文本中的空行、缩进、换行方式及编码；支持 UTF-8（含 BOM）和带 BOM 的 UTF-16 LE/BE。拒绝二进制或无法识别编码的文件，不会修改原文件；暂不自动识别 GBK。
- 工具栏新增 Diff：当前标签与其前一个同类型标签左右对比，支持新增、删除、修改行及行内差异高亮、同步滚动和差异跳转（F7 / Shift+F7，Esc 关闭）。不同后缀的纯文本文件可互相对比。
- 对比读取编辑器中的当前内容；Markdown 对比源码，TDE 对比事件正文、创建时间、截止时间和完成状态，不比较图片像素或纯样式变化。
- Diff 按需加载，在独立 Worker 中计算并虚拟化显示长文件；复杂差异采用整段对齐并提示，不遗漏内容。
- 修复纯文本自动保存后撤销回初始内容时，撤销结果未正确写回磁盘的问题。
- 修复 Diff 滚动尚未完成时跳转差异可能显示错误范围的问题，统一两侧水平滚动条占位以保持末尾对齐。
- 补全首个无分隔线事件的截止时间和完成状态对比。
