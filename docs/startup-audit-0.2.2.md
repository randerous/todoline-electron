# 0.2.2 启动专项复查

本次以已完成事件导航改动的 0.2.2 构建为基线，检查主进程、数据库、会话恢复、渲染器依赖、编辑器装配、行号与事件导航、Markdown 附加资源、搜索/提醒/图片辅助窗口。

## 已实施

- 数据库按需启动。空白窗口和只有 Markdown 的会话不启动 SQLite 进程；已知要恢复或命令行打开 TDE 时提前预热，与窗口及渲染器加载并行。首次新建 TDE 时再启动。首次运行先判断旧版配置文件是否存在，避免为不存在的迁移来源启动数据库。
- 增加受主窗口来源验证的会话恢复接口，只读取已保存会话中的授权路径。恢复不重排最近文件，也不为每个标签同步写入两份配置文件。显式打开、新建、重命名等仍更新全软件共享最近记录。恢复保留逐文件错误隔离、原顺序及按路径确定活动标签。
- 首次编辑器装配暂时脱离页面，保留原有滚动容器层级，完成插件和光标设置后同步挂回原位置。避免 Chromium 在插件配置阶段通过 getSelection() 强制排版中间状态；异常时也恢复原容器。已访问标签不会重新挂载，撤销与异步编辑仍使用同一编辑器。
- 行号宽度在首次布局前确定，避免启动时先排版再修改正文宽度。位置读取与标签更新分批进行；节点引用在文档变化后失效，避免滚动时重复从文档起点查找节点。
- 上一项事件导航需求一并保留：只渲染可见导航行，正文滚动采用二分索引与每帧合并，普通可见项轻度高亮，搜索匹配金色且不移除其他条目。

## 审查后保留的设计

- 未访问标签仅加载快照，只有活动标签创建编辑器；后台提醒需要修改时才创建对应编辑器。此项之前已实现，本次验证没有退化。
- Markdown 编辑器、公式、代码高亮与语言模块、图片查看器按需加载；原图解码与打印辅助窗口按需创建。纯文字 Markdown 测试确认不加载公式与高亮资源。
- SQLite 文件结构/完整性、外部修改检查、恢复日志、保存确认和备份保持原有机制。这些检查涉及数据保护，不用删除检查来换取启动数字。
- 搜索与提醒窗口并非在启动时创建。渲染器首屏仍含通用编辑基础库；进一步拆分 TDE 编辑器需要处理同步快捷键、后台提醒及格式转换的初始化契约，本次没有为小额加载收益扩展这部分风险。
- 大型活动文档仍完整挂载可编辑正文。进一步虚拟化正文涉及跨事件选择、输入法、表格和图片布局，不能直接套用导航列表虚拟化。活动文件优先、其余文件渐进恢复也需处理恢复中关闭/重排/退出与跨文件提醒的一致性，列为后续更大改造。

## 测量方法

使用同一机器、同一 Electron、两份打包 EXE，五种场景交替启动。每次使用独立数据目录，文件缓存保留，窗口从创建起可见，关闭提醒。记录从自动化发起启动到活动文档可编辑/空白欢迎页就绪的总耗时；包含 Playwright 连接开销，不等于严格冷启动时间。

`paintedMs` 只是再等待两次动画帧的采样指标，并非屏幕实际呈现的硬件时间；桌面焦点调度会让它波动，结论以可编辑耗时为主。内存记录为 Electron 各进程工作集之和，包含共享内存及波动，不视为精确私有内存。

诊断阶段曾尝试只用 display:none 合并初始化，未发现收益后已撤销。首次“完全延迟数据库”方案导致 TDE 等待，最终增加了已知 TDE 会话的并行预热。CPU 剖析与开发构建试验数据不用于正式前后百分比。

复测命令与最终结果见下方最终验证记录。

## 最终验证记录

2026-09-18，五场景各 5 次优化前和优化后启动，共 50 次。以下为可编辑耗时中位数，减少为负表示采样中变慢。

| 场景 | 优化前 | 优化后 | 耗时减少 |
| --- | ---: | ---: | ---: |
| 空白窗口 | 1250 ms | 1323 ms | -5.8% |
| 30 事件单文件 | 1524 ms | 1472 ms | 3.4% |
| 5,000 事件单文件 | 2472 ms | 2264 ms | 8.4% |
| 4 标签，各 1,500 事件 | 1688 ms | 1668 ms | 1.2% |
| 80 节 Markdown | 1156 ms | 1117 ms | 3.4% |

5,000 事件场景每个成对样本都有改善，中位数减少约 0.21 秒（8.4%）。空白窗口本轮中位数增加 73ms；小文件、多标签和普通 Markdown 的整体变化较小，不据此声称所有启动场景都大幅提速。空白与纯 Markdown 每次均由 1 个数据库进程降至 0 个；这两个场景总工作集中位数分别从 450/474MB 降为 384/406MB，工作集存在共享和波动，仅作参考。

原始结果及两份程序的 ASAR 校验值：[startup-performance-0.2.2.json](startup-performance-0.2.2.json)。基线是本次导航改动完成后、启动专项开始前的 0.2.2 构建，不是此前已发布的 0.2.1。


类型检查和生产构建通过；48 项相关单元测试通过。打包程序专项共 24 项：启动 7、行号 7、Markdown 5、事件导航 5。最后一次修改仅增加数据库预热，之后启动/行号/Markdown 的 19 项在最终 EXE 上通过；导航 5 项在完全相同的渲染器构建上通过。没有运行不相关的全量 E2E。
