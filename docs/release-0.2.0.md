# 0.2.0

- 修复新标签自动转为 Markdown 后，界面中的最近文档列表未刷新的问题。最近记录由主进程统一广播，所有标签共享，关闭标签及重启后仍可重新打开。
- 修复 Ctrl+点击 Markdown 链接时误选整个段落、出现蓝色外框的问题，保持文本光标及正常打开链接行为。
- 外观与设置新增“新文件保存位置”。选择目录后，后续新建 `.tde` 及自动转换的 `.md` 在该目录自动保存；已有文件不迁移，继续写入原路径。支持恢复默认，重启保留设置，新建时避免覆盖同名文件。
- `.tde` / `.md` 图片支持双击查看原图。提供原始分辨率信息、原始大小、适应窗口、按钮/滚轮缩放、拖动、复制原图和 Esc 关闭。查看与缩放不会修改文档图片尺寸。
- Markdown 自动判别增加“加粗小标题、行内代码、列表”的组合；已将用户提供的 openEuler Next 长文加入回归样本。仅全新空白标签可以自动转换，普通文字、孤立粗体、简单列表或单个行内代码仍不触发。
- 剪贴板 HTML 只是普通文本外壳、但文本本身带 Markdown 结构时，按 Markdown 解析，避免自动转换后仍显示原始星号和反引号。
