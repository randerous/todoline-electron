# 0.1.49

- 推迟提醒的输入框默认完整显示“10分钟后”，包含可编辑的“后”字，右侧按钮固定为“提醒”。输入未带“后”的时长会补全；完整文本与事件截止时间保持一致。
- 确认推迟后，同步修改并保存事件的截止时间文本和时间戳，更新待提醒及逾期列表。先保留新提醒计划，再等待事件保存确认，防止提前提醒设置导致立即重复弹窗。保存失败保留原提醒及正文编辑，可重试。
- 列表容器原本有上下各 3px 的额外边距，普通段落没有。移除这层默认边距，列表去掉序号时不再因容器边距变化发生垂直跳动；显式设置的段落格式仍保留。
- 从正文向上拖选到分隔线时，分隔线显示与文本选区一致的高亮，并作为选区的一部分。Delete、Backspace 删除该分隔线和所选内容，保留选区之外的内容，支持撤销；首条分隔线同样适用。

仅运行本次相关检查。最终验证结果见 `packaged-0.1.49.json`，发布包完整性记录见 `release-0.1.49.json`。
