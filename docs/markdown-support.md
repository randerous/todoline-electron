# Markdown 支持

本功能随 0.1.50 本地发布。现有 0.1.49 发布包未被覆盖。

0.2.0 补充了全局最近文档同步、新文件保存目录、双击原图查看和组合格式自动判别，详见 [0.2.0 更新说明](release-0.2.0.md)。

## 文件与粘贴规则

Markdown 使用独立的原生文本存储和编辑器，与 `.tde` 的 SQLite 事件存储共用标签、搜索、主题和窗口。`.md` / `.markdown` 可通过打开、拖入、启动参数、最近文档或会话恢复打开。重复打开定位同一个标签。

新标签仍为 `.tde`。自动转换只允许新建、未确认保存、从未输入内容的空白草稿；保存过的空文件、曾编辑后清空的标签均不转换。完整代码围栏、表格、块公式、多级标题等结构触发转换，普通文字、单个井号标题、孤立粗体或简单列表不会触发。撤销转换粘贴恢复原 `.tde` 草稿；明确保存后固定当前文件类型。

`.tde` 沿用外部纯文本粘贴。`.md` 优先解析剪贴板中的语义 HTML，其次解析 Markdown 文本；在代码块内始终按原文插入。编辑等待期间仍保留原落点，若原选区被修改则提示重新粘贴，避免覆盖新输入。

0.2.0 起，“加粗小标题、行内代码、列表”的组合也可以触发转换。若剪贴板 HTML 只是普通文本外壳、而纯文本中保留 Markdown 标记，则直接解析 Markdown。新文件保存目录在“外观与设置”中选择，仅影响以后新建的文件；打开原有文件继续保存在原路径。

## 格式范围

| 内容 | 行为 |
| --- | --- |
| 标题、段落、引用、列表、链接 | 可编辑；目录支持 H1–H6、折叠、定位和滚动跟随 |
| GFM 任务列表、删除线、表格 | 可编辑；保留勾选、编号起点和列对齐 |
| 合并单元格、多段表格 | 以 HTML 表格写入 Markdown，保留合并结构 |
| 行内与块公式 | 保留 LaTeX，点击公式编辑源码；支持美元符号和聊天常见反斜杠定界符 |
| 代码块 | 保留语言与缩进，常用语言按需高亮；未知语言正常显示原始代码 |
| Front matter、脚注、未知语法及未知 HTML | 以可编辑源码节点保留；不执行 HTML 脚本 |
| 本地图片 | 文档目录内相对路径；粘贴图片存入附件目录；另存为携带引用附件 |
| 远程图片 | 保留 URL 和替代文本，目前以占位内容显示，不自动下载 |

以格式语义为保留目标，不复制聊天网站的网页布局、按钮、背景和字体。未携带 LaTeX 的公式只能保留文本并提示；截图公式不执行 OCR。字形、字号和主题遵循软件设置。Markdown 标准没有的任意网页样式，不承诺可视化编辑后原样保留。

未编辑文件不重写，保留原始字节；编辑后使用统一 Markdown 排版，因此空行、强调符号、引用链接写法可能规范化。原有 UTF-8 BOM、LF/CRLF 格式保留；非 UTF-8 或二进制文件拒绝作为 Markdown 打开。

## 保存与恢复

保存先写恢复记录，再使用同目录临时文件、刷盘和替换写入。保存前检查磁盘摘要；检测到外部修改时保留当前编辑，要求另存为或重新加载。重新加载先保留编辑内容及引用图片的恢复副本。另存为不会覆盖另一个已打开标签，遇到目标目录同名不同内容的附件会中止。

相对图片限定在文档目录树内，不读取目录外文件或跳出目录的符号链接。重命名不更改已有附件引用；分享或手动移动时应携带对应附件目录。自动保存与普通 `.tde` 使用相同的约半秒延迟，异常退出仍可能丢失尚未提交到保存队列的最后输入。

## 启动设计

Markdown 编辑器、解析器、KaTeX、字体和高亮语言均按需加载。后台标签在首次访问前不创建编辑器；跨文件搜索可以仅解析其文本。公式临近可见区域时渲染，代码高亮异步执行，大代码块保留普通代码显示。

## Markdown 首版验证（0.1.50，2026-09-18）

类型检查与生产构建通过；14 个相关单元测试文件共 151 项通过，定向窗口测试共 32 项通过（10 项 Markdown、10 项右键/列表/选区回归、7 项重命名与迁移、4 项基础编辑/搜索/保存冲突、1 项推迟提醒同步）。没有运行全量 E2E。

覆盖了原生 Markdown 保存、未编辑字节保留、UTF-8/BOM/换行、外部修改冲突、恢复副本及附件迁移、未知源码保留、ChatGPT 类 HTML 公式与代码、目录折叠/更新、图片跨文档复制、拖入去重、空白草稿自动转换与撤销、滚动恢复、后台文件搜索、离线公式 PDF。聊天粘贴使用真实 Electron 剪贴板和包含 KaTeX 的代表性 HTML 样本；未逐一验证所有聊天网站版本。

旧提醒迁移测试的按钮定位已从“10 分钟后提醒”更新为现有“10分钟后提醒”，迁移断言全部保留。并发运行时曾出现一次单元测试动态导入超时，独立重跑及最终整组重跑均通过；最终测试命令允许 15 秒单项超时以容纳测试模块首次转换。

### 启动基准

同一台机器、同一 Electron 运行时，使用隔离测试会话，计时从 Playwright 启动到活动编辑区可编辑。基线来自本地已发布的 0.1.49，解包到独立目录；新旧交替运行，每个场景各 7 次。以下为中位数：

| `.tde` 场景 | 0.1.49 | 当前构建 | 差值 |
| --- | ---: | ---: | ---: |
| 单文件 5000 事件 | 2358 ms | 2316 ms | -42 ms |
| 恢复 4 标签，各 1500 事件 | 1501 ms | 1435 ms | -66 ms |

两项均满足不回退超过 `max(5%, 50 ms)` 的目标。较早分批运行曾产生明显的前后负载差异，因此以交替测量判断回退；原始分批结果也保留，不将上述小幅下降解释为确定的加速收益。

独立 Markdown 批次的中位数：50 节标题正文 847 ms，100 组公式/表格文档 990 ms，后台 Markdown + 前台 1500 事件 `.tde` 1179 ms。各场景均只创建 1 个编辑器；普通 `.tde` 及混合后台场景无 Markdown 编辑器、解析器或公式样式预加载，普通 Markdown 无 KaTeX 样式预加载，公式文档才加载公式样式。

这是隐藏窗口、文件缓存已热的开发构建测量，包含自动化启动开销；不代表冷启动 EXE 耗时，也不代表整篇公式全部渲染完成。原始样本与复算数据见 [启动基准 JSON](markdown-startup-2026-09-18.json)。复测命令：

```powershell
node scripts/benchmark-startup.mjs md-paired-final --baseline=.cache/markdown-baseline-0.1.49 --runs=7
node scripts/benchmark-startup.mjs md-current-final --runs=7 --markdown
```
