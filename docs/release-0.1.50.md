# 0.1.50

- 新增原生 `.md` / `.markdown` 编辑、自动保存、另存为、重命名及会话恢复，拖入文件分别新开标签。
- Markdown 左侧显示可折叠的 H1–H6 目录，支持定位、滚动跟随和实时更新。
- 跳转到文末标题时，目录高亮保持在最后章节，不因正文已滚到底部而退回上一节。
- Markdown 粘贴保留标题、列表、表格、代码和携带 LaTeX 源码的公式；公式可点击编辑，常用代码语言按需高亮。
- 新标签仍默认 `.tde`；仅全新且尚未保存的空白标签，在粘贴明确 Markdown 内容时自动转换，撤销可恢复原空白标签。
- 本地图片使用相对附件目录，另存为迁移附件，跨 Markdown 文档复制图片生成独立附件；支持离线公式 PDF 导出。
- Markdown、公式和高亮组件按需加载。交替启动基准未发现原有 `.tde` 场景性能回退。

兼容范围及测试、性能说明见 [Markdown 支持说明](markdown-support.md)。远程图片目前保留链接并显示占位内容；网页外观按软件主题重排。

本机 EXE：`dist/release-0.1.50/win-unpacked/TodoLine Electron.exe`。

便携包：`dist/TodoLine-Electron-0.1.50-win-x64.zip`。

源码包：`dist/TodoLine-Electron-0.1.50-source.zip`（包含源码、资源、脚本、锁文件、文档和测试，不含依赖、构建缓存及用户文档）。

保留旧版本；仅本地发布，不上传远程。
