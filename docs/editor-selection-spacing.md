# 编辑行距与不连续选区

- TDE、Markdown 和纯文本默认正文行距均为 1.5；Markdown 普通段落不再叠加额外段后间距。
- 设置中的“正文行距”接受 1.0–3.0 倍、0.1 步进；全局生效并保存到会话配置，不改写文档内容。标题等特殊块仍保留自身排版。
- Ctrl 拖选追加文本选区；Ctrl 单击追加单词，再次点击已选范围取消该范围。重叠选区合并，复制按文档顺序以换行分隔。Ctrl 点击链接仍执行打开链接。
- 三种格式支持多处选区复制、剪切、删除、普通文本替换和撤销。普通点击/拖选重新开始选择；Markdown、纯文本按 Esc 退出多选。输入法开始组合时使用主选区，避免把组合过程重复写入各处。
- TDE 复用既有列/行选区编辑与异步剪贴板保护；Markdown/纯文本使用可映射、可序列化的 ProseMirror 多范围 Selection，保护未选中的间隔文字。
- Markdown 标题选择器改用两边对称的向下箭头。
- 右键工具栏最近文件列表中的条目，直接在资源管理器定位该文件；仅接受主进程最近文件列表中的路径，不打开额外标签或改变排序。
- 点击纯文本滚动画布的空白区域，将光标定位到现有内容末尾；空文档定位到首行。

## 验证

类型检查、生产构建及 64 项相关单元测试通过；6 项定向界面用例分别通过，覆盖三种格式多处选择编辑、Ctrl 单击/右键复制、空白区域点击、行距跨模式与重启恢复、最近文件定位。另核对三种主题的下拉箭头、标题选择和公式插入。
