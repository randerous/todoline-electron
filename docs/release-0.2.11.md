# 0.2.11

- TDE、Markdown、纯文本默认正文行距统一为 1.5 倍，取消 Markdown 普通段落额外间距；设置中的“正文行距”支持 1.0–3.0 倍、0.1 步进，全局生效并重启保留。
- 支持 Ctrl 拖选追加不连续文本选区，Ctrl 单击追加单词或取消已选范围。支持复制、剪切、删除、普通文本替换和撤销，保留未选中的间隔文字。右键点击任一选区可复制整组内容。Ctrl 点击链接保持原有行为。
- 输入法组合输入暂作用于主选区，避免重复写入组合文字。
- 标题下拉菜单使用两边对称的向下箭头。
- 右键工具栏最近文件条目，在资源管理器定位文件，不增加标签、不改变最近文件排序。
- 点击纯文本画布空白处时，光标定位至现有内容末尾；空文档定位至首行。
