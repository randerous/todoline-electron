# 0.2.8

- 标签重命名可编辑完整文件名（包括后缀），默认仅选中文件名主体。编辑时保持原标签宽度，无额外蓝色外框。
- `.md` / `.markdown` 与其他文本后缀互改时保留源码，立即切换 Markdown / 纯文本编辑器及目录导航；可移除后缀。UTF-16 文本改为 Markdown 时转为 UTF-8，保留文字及换行。
- 涉及 `.tde` 时执行实际内容转换，先完成目标文件并成功打开，再移除原路径；同名文件和外部修改会阻止转换。原文件保留在恢复目录，可通过“查看恢复文档”打开所在位置。
- TDE 转 Markdown 保留正文、基本格式、图片及时间/状态文字；转纯文本使用文字和图片占位符。Markdown 转 TDE 导入正文及本地图片，公式保留 LaTeX 文字，远程图片保留链接。TDE 的事件边界与提醒配置不在 Markdown 中运行，转回 TDE 作为一个事件；完整原结构保留在恢复副本中。
- Markdown 支持 Ctrl+1～6 将当前段落或选中段落设为对应级别标题，再按相同快捷键恢复正文。标题级别菜单提示中列出快捷键。
- 工具栏新增自动换行开关，位于比较按钮左侧；默认开启，适用于 TDE、Markdown（含代码块）及纯文本正文。所有标签共享，重启后恢复。仅影响显示，不写入软换行；Compare 保持逐行对齐显示。
