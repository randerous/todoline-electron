# 0.2.4

- 左下角快速搜索与 Ctrl+F 共用查询、搜索选项、自动定位及正文/事件导航高亮；事件导航保留完整列表，Markdown 搜索正文而非筛选目录。
- 快速搜索失焦时取消搜索高亮并保留查询文字，再次聚焦自动全选文字并恢复搜索。处理主窗口与浮动搜索窗口之间的焦点切换。
- 清除按钮替换为上一个、下一个匹配按钮，支持循环跳转；点击按钮保留输入框焦点，Enter / Shift+Enter 同样可跳转。
- 小窗口或较窄搜索框保持上下排列；窗口宽度至少 960px 且搜索框内容宽度至少 140px 时横排，上箭头在左、下箭头在右。使用 CSS 自动布局，无额外窗口尺寸监听。
- 修复 Markdown 编辑器未持有焦点时，搜索选中匹配内容但未滚动到目标的问题。

## 验证

本次修改已完成类型检查、生产构建、20 项相关单元测试及 10 项相关界面测试。箭头布局检查覆盖小窗口、普通窗口、宽侧栏、窄侧栏四种组合。打包程序检查结果记录于 `packaged-0.2.4.json`，归档一致性及 SHA-256 记录于 `release-0.2.4.json`。
