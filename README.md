# TodoLine Electron

[![CI](https://github.com/randerous/todoline-electron/actions/workflows/ci.yml/badge.svg)](https://github.com/randerous/todoline-electron/actions/workflows/ci.yml)
[![macOS portability](https://github.com/randerous/todoline-electron/actions/workflows/macos.yml/badge.svg)](https://github.com/randerous/todoline-electron/actions/workflows/macos.yml)

独立的 Windows 待办编辑器。Electron + TypeScript + React + Tiptap/ProseMirror，保持 TodoLine Qt 版 `.tde` SQLite 文件格式。默认深色，支持浅色、绿色画布及跟随系统主题。

源码位于 `E:\todoline\TodoLine-Electron`，与 `E:\todoline\Todoline` 并列。独立 Git `main`。原项目源码和发布程序均保留。

## 本地运行

当前电脑已配置 Node 24、pnpm 11、Electron 40.10.6 和对应 SQLite 原生模块。PowerShell 执行：

```powershell
cd E:\todoline\TodoLine-Electron
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1
```

`setup.ps1` 安装锁定依赖、验证 Electron 原生模块 SHA-256 并编译。Electron 自身二进制按 npm 包中的官方校验和验证。Node 测试用和 Electron 用的 SQLite 原生模块分别保存，避免 ABI 混用。本机不需要额外安装 Visual Studio。

Windows 剪贴板和图片解码助手从项目内 C/C++ 源码编译，开发机需 MinGW-w64 GCC/G++。本机使用 `E:\Qt\Tools\mingw1310_64\bin`，其他位置可设置 `CC`、`CXX` 或将编译器加入 PATH。助手只链接 Windows 系统 DLL；便携包使用者不需要安装 GCC、Qt 或 .NET。

## 开发与持续集成

- Windows 完整流程保持不变：`scripts/setup.ps1` → `scripts/dev.ps1` → `pnpm typecheck` / `pnpm test` / `pnpm build` / `pnpm test:e2e` / `pnpm package`。
- macOS 开发链路（不改变 Windows 流程）：`pnpm prepare:mac`（下载 Electron 与 Node/Electron 两种 ABI 的 better-sqlite3 预编译）→ `pnpm build:mac` → `pnpm dev:mac`。界面回归用 `pnpm smoke:mac`（39 项，真实 Electron + 真实 `.tde` 落库断言）。说明与实测结果见 [macOS 兼容性报告](docs/macos-portability.md)。
- 依赖本机产物的测试会显式跳过而不是失败：Qt 往返校验需要 `scripts/build-qt-compat.ps1` 生成的 `.cache/qt-compat/qt-compat.exe`，WIC 图片助手需要 Windows。其余用例在 CI 中必须全绿。
- GitHub Actions：
  - `ci.yml`：Windows x64 上类型检查、单元测试、构建（MinGW 编译剪贴板与图片助手）并上传 `out/`；另有一个 macOS 类型检查与单元测试任务。
  - `macos.yml`：macOS 构建 + 39 项界面冒烟，防止可移植性回归。
  - `release.yml`：推送 `v*` 标签时执行类型检查、单元测试、打包 Windows zip 并创建 GitHub Release。
  - `e2e-selfhosted.yml`：42 项 Playwright 界面回归需要本机 Qt 6.8.3、MinGW 与同级 `Todoline` 项目的 `libtlcore.a`，因此只在带 `self-hosted, windows, qt` 标签的机器上手动触发。

## 校验和打包

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
pnpm package
```

完整本地发布脚本：`powershell -ExecutionPolicy Bypass -File scripts/release.ps1`。产物为 `dist/TodoLine-Electron-0.2.11-win-x64.zip`，解压后运行 `TodoLine Electron.exe`；不需要安装 Node 或 Qt。不会上传或创建 GitHub Release。未压缩的当前版本位于 `dist/release-0.2.11/win-unpacked/`，可直接运行其中的 EXE。

Qt 往返测试读取原项目已编译的 `libtlcore.a`。先执行 `scripts/build-qt-compat.ps1`；所有验证工具和样本都生成在新版 `.cache/` 或 `test-results/`。性能测量使用 `node scripts/benchmark.mjs`，会短暂显示测试窗口。

### Markdown 文档

- 可打开、拖入和直接编辑 `.md` / `.markdown` 文件；多个文件分别打开标签，已打开的文件直接定位原标签。左侧为可折叠的 H1–H6 目录，可点击跳转并随编辑、滚动更新。
- 新标签默认 `.tde`。仅新建、尚未保存且从未输入内容的空白标签，在粘贴带明确 Markdown 特征的内容时自动转为 `.md`；输入后清空或已保存的空文件不会自动转换。撤销这次粘贴可回到原空白 `.tde` 标签。
- `.tde` 沿用原有外部纯文本粘贴策略；`.md` 保留可编辑的标题、列表、表格、代码块、链接和携带 LaTeX 的公式。代码语言、缩进和公式源码会保留，界面颜色、字体使用本软件主题。
- Markdown 自动保存为原生文本。首次保存自动转换的草稿会询问保存位置。支持另存为、重命名、会话恢复、全文搜索及 PDF 导出；Markdown 不创建待办事件或截止时间。
- 插入或粘贴的图片存入文档旁的 `.assets` 目录；移动文档时请一并携带附件。另存为到其他目录会复制引用的附件，跨 Markdown 标签复制图片会生成目标文档自己的附件。
- 公式和语法高亮按需加载，不进入普通 `.tde` 启动路径。兼容范围、限制及实测结果见 [Markdown 支持说明](docs/markdown-support.md)。

### 通用操作与待办文档

- Ctrl+N / O / S / Shift+S：新建、打开、立即保存、另存为；Ctrl+W 关闭标签。
- 文件标签的宽度随文件名（含未保存小圆点）变化，不再统一拉到固定宽度；标签栏本身也更矮。拖动文件标签调整顺序，靠近边缘自动滚动；Esc 或拖出标签栏取消。顺序随会话保存。
- 双击文件标签或使用标签右键菜单，在标签内重命名；回车确认，Esc 或失焦取消。支持仅修改大小写；校验 Windows 文件名并阻止覆盖同名文件。
- Ctrl+H 插入分隔线：光标停在空行时该行直接变成分隔线，不再多出一行；只有当空行下面紧接着另一个事件时，仍按原来的方式在其上方插入分隔线并保留这一空行。Ctrl+A 后按左箭头到首行分隔线前，Delete 删除分隔线并保留正文。正文行首 Backspace 同样可以删除。
- URL 后输入空格或回车自动链接；链接末尾第一次 Backspace 取消链接，第二次删字。Ctrl+单击打开链接；工具栏可插入、修改或移除链接。
- 工具栏“段落与字符格式”提供四种对齐、缩进、上下标、引用、代码块和行内代码；支持选中文本所在的多个段落，格式修改可撤销。
- “段落与字符格式 → 表格…”提供表格操作。Tab / Shift+Tab 切换单元格，在最后一格按 Tab 新增行；单击行号选择表格行，拖动跨单元格形成矩形选区。Markdown 使用 HTML 表格保留合并关系，纯文本按制表符分隔单元格，PDF 保留排版和图片。
- 悬停在单元格右边界可拖动列宽，RTL 表格使用左边界。拖动时显示宽度指示线，松开后一次保存、一次撤销；内部边界调整相邻两列，最外侧边界调整总宽度。Esc、窗口失焦或拖动期间输入会取消预览，未移动的单击不改文件。
- Ctrl+单击表格行号可增减非连续行，Shift 扩展、Ctrl+拖动追加经过的行。跨行合并单元格覆盖的行一起选择，状态栏显示行数和字数。复制、剪切、Delete 清空及粘贴仅作用于选中单元格；“表格 → 删除选中行”移除整行。粘贴跨行合并内容时在未选行的间隔处分开，保留一份正文。选区使用半透明高亮，文字和图片保持可见。
- Ctrl+Z / Y：文本、事件结构、完成状态和图片尺寸统一撤销/重做。
- 粘贴的只读旧格式事件保留原始 HTML，可整次撤销和重做；在正文中间插入时保留两侧正文及后段截止信息。文档全为只读内容时也支持 Ctrl+A、Ctrl+C 和 Ctrl+V；直接修改或覆盖已有只读正文仍会被阻止。
- Ctrl+B / I / U：加粗、斜体、下划线；Ctrl+L 有序列表。Ctrl+单击链接打开网页。
- 单击分隔线选中事件，Ctrl+单击多选；Ctrl+Shift+C / X / V 复制、剪切、粘贴事件。
- 完整事件和富文本片段中的图片会先统一验证、再整批保存；共享图片只导入一次，失败保留原选区。正文和链接里的 `asset:123` 不会被当成图片改写，PDF 同样保留原文。跨列表项复制会保留来源列表类型和编号起点。
- 行号覆盖分隔线、段落和嵌套列表，换行仍按一个段落计数；缩进不移动行号。单击行号选中整行，Ctrl/Shift+单击及拖动多选，拖出视口自动滚动。Alt+拖动进行列选择，输入或删除一次作用于所有选择范围。
- 图片可批量拖入或通过工具栏多选插入；同一批次按文件顺序插入并一次撤销，连续批次分别撤销。等待期间可继续编辑或切换标签，落点和初始显示宽度保持不变。原图批量事务写入，坏图会取消整批并提示文件名；状态栏显示待导入数量。八个手柄只改变显示尺寸，原图 BLOB 不因缩放重编码，复制到外部提供原分辨率。
- 在资源管理器复制图片文件后按 Ctrl+V，可按剪贴板顺序批量插入，保留 Unicode 文件名和原图字节，一次撤销整批。源文件丢失或某张图损坏时保留当前选区，不插入半批图片；混有非图片文件时按文件 URL 文本粘贴，不读取其他文件内容。
- TIFF、BMP、ICO 使用 Windows WIC 在独立助手进程中解码，生成显示、复制和 PDF 使用的 PNG 预览，数据库仍保存原文件字节。多页 TIFF、多尺寸 ICO 与 Qt 一样默认显示第一幅；其他页和尺寸保留在原图中。预览缓存限 32MiB/16 张；单图限 100MiB 编码数据、6400 万像素及 32768px 单边，失败时整批取消。
- GIF、WebP 支持静态、透明和动画图片，编辑区直接播放原始动图，跨文件复制保留动画和显示尺寸；系统图片复制和 PDF 使用原分辨率的第一帧。解码在临时沙箱窗口内完成，成功、失败或进程中断后均关闭，正常退出等待已请求的导入保存。当前 Qt 6.8.3 对极小 WebP 的已知读取限制见审计记录，新版保留这些文件的原字节。
- 快速复制/粘贴按顺序执行；读取剪贴板或图片期间移动光标，仍插入原来的位置。等待期间原选区被修改时会提示重试；中文组合输入结束后再提交粘贴。
- 截止时间支持旧版解析语义，例如“明天下午3点”“2小时后”；输入框贴合文字居中显示，回车或移开光标即按当前内容重新解析，“1 分钟后”这类相对写法每次离开输入框都从当时重新计时，固定日期则不会漂移。提醒弹窗直接显示事件正文，提供“10 分钟后提醒”“我知道了”“已完成”“打开事件”，支持未处理队列重启恢复与去重。窗口隐藏到托盘时仍可提醒；锁屏和休眠时暂停展示，解锁后继续。指向或编辑时不画下划线而是整块反色，出现光标后“设置截止时间”提示随即消失；悬停片刻会显示说明——未填写时给出可用格式，已识别时显示“已识别截止时间 …”，无法识别时说明将按原文保留。
- 分隔线上创建时间始终位于整行正中；截止时间靠在剩余时间左边，两者之间与剩余时间到行尾的间距相同；未设置截止时间时截止时间贴在最右侧、只留一小截分隔线。
- 正文滚动后右下角出现“回到顶部”按钮，单击回到文档开头且不移动光标。
- 工具栏的“− 15 px +”字号步进位于“加粗”左侧：有选中文字时改选中文字，没有选中时调整正文字号。“段落与字符格式 → 文字字号”可增大、减小或恢复选中文字的字号，写入 Qt 使用的 pt 单位；“外观与设置 → 正文字号 → 应用到全部”清除粘贴文字自带的字号，使整篇跟随设置里的正文字号（可一次撤销）。
- 左侧只显示事件导航，每个事件一行，底部提供“打开所在文件夹”和日历按钮（按截止时间把事件排进月视图，单击某条即定位到正文；某天事件较多时，指向格子里的“展开全部N个”停留 0.3 秒，就会在格子旁边（哪侧有空间就往哪侧）弹出气泡列出这一天的全部事件，指针移到气泡上不会收起，单击可钉住；没有截止时间的事件不在日历中显示）；从事件导航或状态栏列表定位事件时，该事件停在正文顶端。正文区直接从内容开始。工具栏可在“外观与设置”里设为自动隐藏，指向标签栏或其下方细条即可临时展开，展开时不移动正文。
- 搜索为独立浮动窗口，可拖到主窗口外，默认在鼠标位置旁打开，按住面板空白处（或左侧握柄）即可拖动，焦点不在其中时半透明；输入后自动跳到第一个命中事件并停在正文顶端。面板第二行是一排开关：区分大小写（Aa）、全词匹配、高亮、整段，以及“当前文件 / 所有打开文件”和“全选命中”。命中文字与整段命中事件默认都用金色高亮，整段高亮是一整块底色，不再按段落分块或加左侧竖线；选“所有打开文件”时结果带上文件数，上一个/下一个会自动切到命中所在的标签。所有选项按标签分别记忆。
- 状态栏右侧的事件计数悬停 0.3 秒展开对应列表，每个列表只显示自己的事件，每个事件一行，按日期由近及远排序（没有截止时间的排在最后）；过滤框在列表下方，指向某一行时在列表旁展开内容预览。移开指针后列表自动收起，单击展开的列表会保持打开。
- 在列表项行首按 Backspace（第一项除外）会把这一项并为上一项的续行，列表保持完整、下方编号随之减一；再按一次把文字接到上一行。删除操作让两个同样式列表挨在一起时自动合并，编号接续。
- 列表第一项（或从第一项开始选中的多项）按 Tab 时单独成为下一级并换成该级样式，下面同级的项重新编号；Shift+Tab 退回后与同级列表合并恢复编号。有序列表内右键可选“继续编号”，接着同一事件中上方最近的同级有序列表往下编号。
- 多行编辑：选中多行按 Tab 时每行一起缩进一级（4 个空格），Shift+Tab 一起退回一级；选中多个列表项时一起下沉或上移一级。选中若干普通行后，可在右键菜单或工具栏选择“有序列表 / 无序列表”（Ctrl+L 为有序列表），按每行行首缩进确定级别——一个制表符或 4 个空格为一级，缩进相同同级、变浅回到对应级别，没有缩进或无法判断时为第一级——并去掉行首缩进。有序列表各级为 1. → (1) → ① → ■ → ●，无序列表为 ● → ○ → ■。
- 多级列表：光标在列表项开头按 Tab 缩进一级并开启下一级列表，依次为 1. 2. 3. → (1) (2) (3) → ① ② ③ → ■ 实心方块 → ● 实心圆点，最多 5 级；Shift+Tab 退回上一级。缩进到已有的下级列表时沿用该列表的样式。工具栏“列表样式”按钮和列表内的右键菜单都可以手动选择样式：有序 1. / (1) / ① / a.，无序 ■ / ● / ○。所选样式只作用于光标所在行或选中内容覆盖的行，同一列表的其他项保持原样式与编号（选回原样式会自动合并回同一个列表）；光标不在列表中时直接把该行变成所选列表。Qt 原生支持 (1)、a.、i.、■、●、○，保存后在 Qt 版中显示一致；① ② ③ 是新版独有样式，被 Qt 再次保存后会变回 1. 2. 3.。
- 在正文上单击右键弹出常用操作：撤销、重做、剪切、复制、粘贴、全选（附快捷键提示）。右键落在已选中的文字内会保留选区；落在别处会先把光标移到该处，因此粘贴就插在指向的位置，没有选中内容时剪切/复制置灰。菜单按实际尺寸夹在窗口内，Esc 关闭；在分隔线上右键仍是原来的事件菜单。
- 导出 Markdown、纯文本、PDF 后，在窗口右下角显示与主题一致的完成卡片（文件名、完整路径、“打开所在文件夹”与“知道了”），不再弹出系统对话框。
- 工具栏“最近打开的文档”支持路径筛选与键盘选择；打开其他文档时也可使用。
- 可将一个或多个 `.tde` 路径作为启动参数，或使用 `--open 文件.tde`；已运行时交给现有窗口，不另开写入实例。`--quit` 等待保存后退出，忽略关闭到托盘设置。

## 数据与兼容

配置、会话、恢复日志和未命名草稿保存在 `%APPDATA%\TodoLine-Electron`。首次运行只读取 Qt 可转换设置，保留其原会话。

设置文件按字段校验，保存时刷盘并原子替换，同时保留上一份有效会话 `session.json.bak`。损坏文件另存为 `session.corrupt-*.json` 后尝试恢复备用会话。普通窗口位置、大小和最大化状态分别恢复，显示器布局改变时将窗口移回可见范围；草稿使用独立目录和“未命名 1、2…”的递增标题。

编辑器 JSON 只在内存中使用；保存仍写 Qt HTML、原事件元数据和资产表。未改正文保留原始 HTML；移动光标、选择和关闭不会自动补空段或改写正文，撤销回打开时的正文也恢复原始 HTML。无法可靠转换的格式以只读事件显示并保留原文。首次写入已有文件前生成 SQLite 一致性备份（包括 WAL）；检测外部写入后停止自动覆盖。

自动保存防抖 500ms，经后台事务确认后显示成功。失败保留内存内容和已进入保存队列的恢复日志；关闭时等待保存。恢复内容遇到磁盘冲突时可另存为。未进入保存队列的最后 500ms 输入不承诺在强制结束进程后恢复。
